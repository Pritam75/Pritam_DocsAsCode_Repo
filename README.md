# Docs-as-Code Portfolio: AI Alerts API Documentation

This repository demonstrates a docs-as-code approach by transforming traditional HTML-based AI Alerts API guide into a structured, Git-based Markdown (`.md`) files.

## Repo Structure

```text
docs/
└── ai-alerts-api/
    ├── index.md
    ├── overview.md
    ├── endpoints.md
    ├── query-parameters.md
    ├── response-format.md
    ├── examples/
    │   ├── list-alerts.md
    │   └── get-alert-details.md
    ├── schemas/
    │   ├── alert-summary-schema.md
    │   └── alert-details-schema.md
    └── response-codes.md
```
