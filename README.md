# Docs-as-Code Portfolio: API Documentation

This repository demonstrates a docs-as-code approach by transforming traditional HTML-based API documentation into a structured, Git-based Markdown system.


## What This Project Shows

- Conversion of HTML documentation to Markdown
- Modular documentation structure
- Git-based workflow readiness
- API documentation best practices

## Project Structure

```bash
docs/
├── ai-alerts/          # AI Alerts API documentation
│   ├── overview.md     # API overview and use cases
│   ├── authentication.md  # Authentication details
│   ├── endpoints.md    # API endpoints and examples
│   ├── rate-limits.md  # Usage limits
│   ├── errors.md       # Error handling

``````

## Docs-as-Code Practices Used

- Markdown-based authoring
- Version control with Git
- Modular content organization
- Developer-friendly formatting

## Source

Original HTML documentation from Conviva API guide.
